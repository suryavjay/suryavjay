# Hi, I'm Surya Vijay

I'm a UT Austin student studying Statistics and Data Science and pursuing Plan II Honors. I'm interested in software engineering and machine learning.

## Selected Projects

### [FusionCVCP — 3D Object Detection](https://github.com/suryavjay/FusionCVCP)

At UT Dallas's AI Safety Lab, I co-developed a LiDAR-camera fusion model combining Cross-View Transformers and CenterPoint, resolving training errors to enable multi-GPU training and tuning loss functions, learning rates, and batch sizes. This fork preserves our [shared lab repository](https://github.com/safetylab24/FusionCVCP), which builds on CenterPoint.

### [Waypoint — Internship Data Pipeline](https://github.com/suryavjay/waypoint-job-feed)

A Python pipeline that collects public internship listings from community feeds and employer job boards, with scheduled updates through GitHub Actions. I implemented duplicate matching across boards that preserves distinct job postings, added bounded retries for transient failures, and wrote regression tests for both behaviors.

### [Aptamer Database Search — Literature Extraction](https://github.com/suryavjay/Aptamer-Database-Search)

I built a PubMed retrieval and Gemini extraction workflow that turns research papers into structured aptamer records, then added a Streamlit interface for searching names and sequences. I manually checked the output against three papers and documented failure cases, including lost formatting, irrelevant extractions, and unsupported binding-affinity values.

### [82-0 Draft Helper — NBA Pick Recommendations](https://github.com/suryavjay/82-0.com-solver)

I built a Chrome extension and standalone planner that rank available players for the 82-0 NBA draft game using roster scoring and projected wins. I fixed stale team detection by matching the visible player pool, prevented recommendations for already-drafted players, and corrected overlay behavior that interfered with page clicks.
